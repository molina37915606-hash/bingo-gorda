ACTUALIZAR A V10.6 EN GITHUB

1. Descomprimí Actualizacion_V10_6_para_GitHub.zip.
2. Entrá al repositorio bingo-gorda.
3. Tocá Add file y después Upload files.
4. Subí TODO lo que está dentro de la carpeta descomprimida, manteniendo las carpetas js y tests.
5. GitHub reemplazará los archivos con el mismo nombre.
6. Escribí como mensaje: Actualizacion V10.6
7. Tocá Commit changes.
8. Esperá que Render termine el despliegue y muestre Live.
9. Actualizá /admin y /jugador con Ctrl + F5.

No hagas la actualización mientras haya una partida activa.
