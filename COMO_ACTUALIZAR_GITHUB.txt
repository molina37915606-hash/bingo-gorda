ACTUALIZAR A V10.3 EN GITHUB
============================

1. Descomprimí Actualizacion_V10_3_para_GitHub.zip.
2. Entrá al repositorio bingo-gorda en GitHub.
3. Elegí Add file > Upload files.
4. Arrastrá TODO el contenido descomprimido a la raíz del repositorio.
5. GitHub reemplazará los archivos del mismo nombre.
6. Escribí como mensaje: Actualizacion V10.3
7. Presioná Commit changes.
8. Esperá que Render termine el nuevo despliegue y muestre Live.
9. Recargá /admin con Ctrl + F5.

No hagas la actualización durante una partida activa.
