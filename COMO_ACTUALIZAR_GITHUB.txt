ACTUALIZAR GITHUB CON BINGO DE LA GORDA ALFA

1. Descomprimí el ZIP de ALFA.
2. Reemplazá el contenido del repositorio por esta versión.
3. Conservá/configurá en el hosting MASTER_ADMIN_PASSWORD, PUBLIC_URL y BINGO_DATA_DIR.
4. Ejecutá: npm test
5. Subí los cambios.
6. Verificá /healthz y después una sala GRATIS de prueba antes de usar una sala PAGA.

IMPORTANTE: si BINGO_DATA_DIR no apunta a almacenamiento persistente, un reinicio/redeploy puede perder los datos.

Etiqueta sugerida: bingo-de-la-gorda-alfa-5.0.0-alpha.1
