ACTUALIZAR BINGO DE LA GORDA - VERSIÓN BETA EN GITHUB

1. Descomprimí Bingo_de_la_Gorda_Version_Beta_para_GitHub.zip.
2. Entrá al repositorio de GitHub que usa Render.
3. Tocá Add file y después Upload files.
4. Subí TODO el contenido descomprimido, manteniendo las carpetas assets, js, data y tests.
5. Confirmá que GitHub reemplace los archivos anteriores.
6. Escribí como mensaje: Bingo de la Gorda - Version Beta
7. Tocá Commit changes.
8. Esperá que Render termine el despliegue y muestre Live.
9. Actualizá /admin y /jugador con Ctrl + F5.

No hagas la actualización mientras haya una partida activa.
