COMO PUBLICAR GRATIS EN RENDER
==============================

PRIMERA PUBLICACION
1. Subí todo el contenido de esta carpeta a la raíz de un repositorio de GitHub.
2. En Render creá un Web Service conectado al repositorio.
3. Configurá:
   Build Command: npm install
   Start Command: npm start
   Plan: Free
4. Variables:
   NODE_VERSION = 22
   ONLINE_MODE = true
   ADMIN_PASSWORD = una contraseña privada
5. Health Check Path: /healthz
6. Publicá y esperá que diga Live.

DIRECCIONES
- Administrador: https://TU-SERVICIO.onrender.com/admin
- Jugadores: https://TU-SERVICIO.onrender.com/jugador

FLUJO RECOMENDADO V10.7
1. Generá entre 2 y 250 cartones sin sortear bolillas.
2. Abrí SALA ONLINE.
3. Configurá de 2 a 60 jugadores y autorizá de 1 a 4 cartones por persona.
4. Elegí una o dos líneas ganadoras y la regla para el mismo jugador.
5. Activá, si corresponde, la asignación automática y elegí de 1 a 30 minutos.
6. Compartí los accesos.
7. Iniciá manualmente la cuenta regresiva cuando todos hayan recibido el enlace.
8. Cuando termine la elección, revisá las asignaciones.
9. Presioná INICIAR SORTEO. El temporizador nunca inicia el sorteo por sí solo.
10. Al terminar, presioná FINALIZAR SORTEO y descargá el PDF o CSV del acta.

LIMITACIONES DEL PLAN GRATUITO
- Puede tardar cerca de un minuto en despertar.
- El almacenamiento del servidor es temporal.
- Descargá copias de seguridad durante partidas importantes.
