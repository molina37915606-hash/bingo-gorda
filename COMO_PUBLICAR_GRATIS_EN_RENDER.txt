PUBLICAR BINGO DE LA GORDA 2.3 EN RENDER

1. Subí el contenido descomprimido a GitHub.
2. En Render creá o actualizá un Web Service conectado al repositorio.
3. Build Command: npm install
4. Start Command: npm start
5. En Environment configurá:
   MASTER_ADMIN_PASSWORD = tu clave privada
   PUBLIC_URL = https://TU-SERVICIO.onrender.com
   ONLINE_MODE = true
6. Publicá y verificá:
   https://TU-SERVICIO.onrender.com/healthz
7. Entrá en:
   https://TU-SERVICIO.onrender.com/admin-principal

ADVERTENCIA SOBRE RENDER FREE

El servicio puede tardar en despertar y sus archivos locales son temporales. Realizá copias de seguridad de las partidas y resultados. No se incluyen administradores temporales en esta versión para evitar depender de accesos guardados en archivos efímeros.
