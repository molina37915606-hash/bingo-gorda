PUBLICAR BINGO DE LA GORDA EN RENDER

- Runtime: Node
- Build command: npm install
- Start command: npm start
- Health check: /healthz

Variables necesarias:
MASTER_ADMIN_PASSWORD=una_clave_segura
PUBLIC_URL=https://tu-servicio.onrender.com
ONLINE_MODE=true

Para conservar partidas entre reinicios, configurá almacenamiento persistente y BINGO_DATA_DIR.


ADVERTENCIA IMPORTANTE
El plan gratuito de Render no garantiza almacenamiento persistente. Sin un disco o servicio
de almacenamiento permanente, un reinicio o una nueva publicación puede borrar partidas,
respaldos y actas. Para uso real configurá un volumen persistente y definí:
BINGO_DATA_DIR=/ruta/del/volumen/bingo

Antes de aceptar dinero real, probá reinicios, restauración de respaldos y descarga de actas
en el entorno definitivo.
