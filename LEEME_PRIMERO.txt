BINGO DE LA GORDA ALFA · 5.0.0-alpha.6

1. Instalar Node.js 18 o superior.
2. Abrir una terminal en esta carpeta.
3. Ejecutar: npm start
4. Abrir: http://localhost:3210/admin

PRUEBAS COMPLETAS:
npm test

IMPORTANTE:
- El Admin principal ahora es /admin.
- Las salas usan una clave compartida y una sesión privada distinta por jugador.
- En partidas pagas el jugador elige sus cartones RECIÉN después de la confirmación del administrador.
- Para uso real en Internet, configurar BINGO_DATA_DIR sobre almacenamiento persistente.

ACCESO ALFA 3:
- Manual: /jugador → clave → nombre/cantidad → sala.
- Directo: enlace de sala → nombre/cantidad → sala, sin pedir clave.

NOVEDAD ALFA 6
- El modo Jugador real fue reconstruido y separado de DEMO.
- La sesión es privada HttpOnly y no se muestra en URL/JavaScript.
- No existe acceso por código personal.
- Nombres únicos y cartones exclusivos se validan en servidor.
- Recuperación de acceso: solo desde Admin, link de un solo uso/15 minutos.
