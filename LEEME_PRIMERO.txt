BINGO DE LA GORDA ALFA · 5.0.0-alpha.1

1. Instalar Node.js 18 o superior.
2. Abrir una terminal en esta carpeta.
3. Ejecutar: npm start
4. Abrir: http://localhost:3210/admin

PRUEBAS COMPLETAS:
npm test

IMPORTANTE:
- El Admin principal ahora es /admin.
- Las salas usan una clave compartida y una sesión privada distinta por jugador.
- En partidas pagas el jugador elige sus cartones RECIÉN después de la confirmación del administrador.
- Para uso real en Internet, configurar BINGO_DATA_DIR sobre almacenamiento persistente.
