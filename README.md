# BINGO GORDA 2026

Plataforma de bingo de 75 y 90 bolas para administrar salas privadas, cartones, reclamos, transmisión y resultados.

## Modalidades

- 90 bolas: AmboCabeza, Primera línea, Segunda línea y Bingo.
- 75 bolas: Línea, Doble línea y Triple línea en el mismo cartón, 4 esquinas y Bingo.

## Uso local

1. Instalar Node.js 18 o superior.
2. Ejecutar `npm start`.
3. Abrir la dirección indicada por la consola.

## Pruebas

Ejecutar `npm test`. Las pruebas cubren ingreso directo, nombres, modo 90, patrones progresivos de 75, resultados y PDF.
