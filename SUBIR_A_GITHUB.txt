EL BINGO DE LA GORDA | Paquete para GitHub Web

1. Descomprimí el ZIP GITHUB.
2. Entrá a la carpeta descomprimida.
3. Seleccioná TODO lo que hay adentro (no el ZIP).
4. Arrastralo a GitHub en “Drag files here to add them to your repository”.
5. Esperá que termine de cargar.
6. Hacé clic en “Commit changes”.

El paquete GITHUB se prepara con la misma lógica funcional que el paquete completo, menos de 100 archivos y sin archivos individuales pesados.
