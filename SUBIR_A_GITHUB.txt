BINGO DE LA GORDA - Beta · paquete para GitHub Web

1. Descomprimí este ZIP.
2. Entrá a la carpeta.
3. Seleccioná TODO lo que está adentro (no el ZIP).
4. Arrastralo a Add files > Upload files en GitHub.
5. Esperá la carga y tocá Commit changes.

Este paquete omite tests y documentación interna, pero conserva el juego y todos los recursos necesarios para producción.
